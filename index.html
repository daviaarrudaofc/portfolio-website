01 / Sobre

Da ideia à API,
com Java.

Meu foco está no backend com Java e Spring Boot. A Library API é meu principal projeto de prática: gerencio livros e autores por uma API REST, separando controllers, serviços, repositórios, validações e tratamento de erros para manter as regras de negócio claras.

Na persistência, trabalho com Spring Data JPA e PostgreSQL; nos testes, exercito cenários de repositório, como regras de autores e ISBN duplicado. É nesse ciclo de implementar, testar e revisar que venho aprofundando modelagem de domínio e contratos HTTP.

A segurança também saiu do plano de estudos e entrou no código: implementei login com Google, um Authorization Server OAuth2 e tokens JWT. Explorei os fluxos de credenciais do cliente, código de autorização com PKCE e renovação de tokens, além da validação de um token em um Resource Server separado. Quero evoluir a cobertura de testes, a documentação e a operação antes de avançar para deploy e cloud.
