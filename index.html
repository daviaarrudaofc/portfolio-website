01 / Sobre

Da ideia à API,
com Java.

Meu foco está no backend com Java e Spring Boot. Tenho transformado ideias em APIs RESTful, conectando regras de negócio a bancos de dados e organizando o código para que cada parte tenha uma responsabilidade clara.

Na prática, estudo modelagem de domínio, persistência com JPA e Hibernate, contratos HTTP e tratamento de erros. Também venho trabalhando com testes unitários e de integração para verificar o comportamento da aplicação, não apenas fazê-la iniciar.

Meu próximo passo é aprofundar a camada de segurança: autenticação e autorização com Spring Security, OAuth2 e JWT, além de login social, Authorization Server e integração entre Spring Boot 4 e Keycloak. Quero levar essas decisões até a documentação, a operação e o deploy.
